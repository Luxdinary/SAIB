## Look in one line

One app window as the stage (editor, docs page, terminal); a violet text marker sweeps over the decisive line, the cursor
clicks it, the camera zooms in, a short callout or stamp explains. Since Q1 (2026-11-01) the ground has depth, code only
(LAYER in scenes.py): dot grid under soft light, a perspective floor grid, blurred code shards in three parallax layers, grain,
edge shadow, and a stage light whose colour follows the status bar. The guiding file (.env) carries a padlock: amber open, green shut.
