# faceless-network

Production system for Stefan's AI short-video network (TikTok, Instagram Reels, YouTube Shorts; German and English).
Rules for Claude are in `CLAUDE.md`. Planning documents live in `C:\Users\Stefa\OneDrive\Business\01 Idee und Strategie`.

Status 2026-10-30: Phase 1 (production chain without publishing) built. Nine brand design systems, nine 10-second demos,
full chain script -> TTS -> word timings -> HyperFrames -> FFmpeg NVENC -> validation -> state machine -> queue, mock publisher
in dry-run, cost logger, tests. No account, no upload, no paid service activated.

## Install (Windows 11)

Prerequisites (already on Stefan's laptop): Git, Node 24, Python 3.13, FFmpeg with NVENC on PATH, NVIDIA driver with CUDA 12 support.

```powershell
cd C:\Automation\faceless-network
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m pip install pytest
npm install
npx hyperframes doctor
copy .env.example .env      # then fill in keys by hand; never commit .env
```

faster-whisper uses the pip wheels `nvidia-cublas-cu12` and `nvidia-cudnn-cu12`; `src/fn/transcribe.py` adds their
DLL folders at runtime. Check: `.\.venv\Scripts\python.exe -c "import ctranslate2; print(ctranslate2.get_cuda_device_count())"` prints `1`.

## Run

```powershell
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\python.exe -m fn.cli status                                  # states, queue, free space
.\.venv\Scripts\python.exe scripts\scaffold_brands.py                        # (re)create brands/<id>/ design files
.\.venv\Scripts\python.exe scripts\render_demos.py                           # nine 10-second demos + overview page
.\.venv\Scripts\python.exe -m fn.cli calendar init ai_security --start 2026-11-05
.\.venv\Scripts\python.exe -m fn.cli script check data\scripts\ai_security-20261105-1-de.md
.\.venv\Scripts\python.exe -m fn.cli produce data\scripts\ai_security-20261105-1-de.md   # mock voice until GEMINI_API_KEY is set
.\.venv\Scripts\python.exe -m fn.cli produce data\scripts\ai_security-20261105-1-de.md --tts gemini   # paid, cents per video
.\.venv\Scripts\python.exe -m fn.cli publish --dry-run                       # mock publisher, nothing leaves the machine
.\.venv\Scripts\python.exe -m fn.cli costs
.\.venv\Scripts\python.exe -m pytest -q
```

Outputs: `storage/<stage>/<video_id>/` with `video.mp4`, `cover.jpg`, `post.json`, `script.md`, `manifest.json`,
`report.json`, `captions.json`; mirrored to `OneDrive\Business\05 Produktion\_Test` (test runs) and `_Demos`.
State: `data/state.db` (SQLite). Costs: `data/costs/costs.jsonl`.

## Layout

| Path | Content |
|---|---|
| `config/` | `brands.yaml` (nine brands), `platforms.yaml`, `policies.yaml`, `voices.yaml` |
| `brands/<id>/` | design system per brand (generated by `scripts/scaffold_brands.py`, editable afterwards) |
| `docs/design-system.md` | shared 9:16 layout, zones, type scale, motion rules |
| `assets/fonts`, `assets/vendor` | OFL fonts with licence files, GSAP with licence note |
| `prompts/` | the Claude Code steps: calendar, research, script, localisation, compliance review |
| `.claude/skills/` | thin skills wrapping the prompts and the CLI (generated by `scripts/scaffold_skills.py`) |
| `src/fn/` | Python package: config, brands, calendar, scripting, tts, transcribe, render, compliance, state, queue, publishing, costs, disk, pipeline, cli |
| `scripts/` | `scaffold_brands.py`, `scaffold_skills.py`, `render_demos.py` |
| `tests/` | pytest suite (`python -m pytest -q`) |
| `automation/` | Task Scheduler templates (not registered) |
| `data/`, `storage/`, `logs/` | runtime data (git-ignored except calendars and scripts) |
